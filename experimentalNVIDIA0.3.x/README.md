# CorridorKey 2.0 experimental Windows build

[Download the experimental Blender extension](corridorkey_compositor-0.3.18-experimental.3.zip?raw=true) and install it in Blender 5.3 or later. In the add-on preferences, click **Set Up CorridorKey** to download the NVIDIA runtime and models.

This build is based on Mac 0.3.18. The `-experimental.3` suffix identifies the experimental build for that Mac version.

I'm looking for testers with Windows and an NVIDIA RTX 30-series GPU or newer. Follow the [setup and test instructions](Setup.md) and include the relevant log if something fails.
Alternatively if you have an agent setup, point it to this adress to do the relevant tests.
I'm mainly looking for:
- if it works at all
- how easy the setup is
- wether there are problems/bugs\
